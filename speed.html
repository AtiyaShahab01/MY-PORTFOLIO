Speed Optimization Case Study

Glitter.com — a Kuwait-based Shopify store. Here's how I took it from a 12 second load time down to 1–2 seconds.

The Problem

The client came to me with a simple but costly issue — their store was taking far too long to load. Pages were slow to open, and it was clearly hurting the experience. The longer the store took to load, the more visitors got impatient and left before they even saw the products, which meant conversions were dropping.

View Speed Proof

What I Did

1

Ran a speed test

As soon as I opened the store, I could tell it was loading slowly. To confirm it, I ran the store's URL through Page Speed Insights — a free Google tool that measures a website's exact loading speed on both mobile and desktop. The result: the store was taking 12 seconds to load on mobile, well above the 3-second benchmark every Shopify store should stay under.

2

Audited the store

I went through the store to figure out why it was so slow. It turned out 13 apps were installed. The client explained that every single one was actively being used for the business, so removing them wasn't an option.

3

Converted All Banner and Product Images to WebP Format

Next, I checked the format and size of the product images and banners — they were saved in regular JPG/PNG format, which made the file sizes unnecessarily large, some up to 5MB each. I converted all of them to WebP format using I Love Img, a format that compresses images to a much smaller size without losing visual quality, helping the store load significantly faster.

4

Removed unnecessary sections

The store had several heavy sections that weren't serving any real purpose — just sitting there adding extra weight. I removed them to lighten the page.

5

Cleaned up the code

Checking the browser console, I found extra CSS and JS files loading on every single page — even on pages that didn't need them. I moved that code out of the global files and into the specific sections where it was actually used, and set the remaining scripts to load with async/defer, so they load in the background instead of blocking the page from displaying.

Understanding the Numbers: Core Web Vitals

Page Speed Insights doesn't just give a single score — it breaks a page's loading experience down into a set of metrics Google calls Core Web Vitals. Each one measures a different part of what a real visitor experiences between clicking a link and being able to actually use the page. Here's what Glitter.com's report showed, and what each metric actually means.

First Contentful Paint

2.4s

The moment the very first bit of content — text, a color, anything — appears on screen. It's the first sign to a visitor that the page is actually loading.

Largest Contentful Paint

6.7s

The moment the biggest, most meaningful element on the page — usually a hero image or banner — is fully visible. Google considers anything under 2.5s "good." Glitter.com was nearly 3x slower than that.

Total Blocking Time

7,920ms

The total time the page was too busy running scripts to respond to a tap or click. This was the single biggest problem on the store, caused by too much JavaScript loading and running at once.

Cumulative Layout Shift

0.004

Measures how much content jumps around while the page loads — buttons shifting, images popping in late, etc. This score was already good, so it didn't need any work.

Speed Index

12.8s

How quickly the page's content fills in visually, from start to finish. This is the metric that most closely matched what the client meant by "the store feels slow."

The pattern here was clear: Largest Contentful Paint, Total Blocking Time, and Speed Index were all in the red, and all three point to the same root cause — too much unnecessary code loading and running before the page could settle. That's exactly why the image compression and the async/defer code cleanup in the steps above made the biggest difference to the final result.

Results

After all these fixes, I ran the speed test again — the store's load time dropped from 12 seconds down to just 1–2 seconds. That's a reduction of over 85%, giving every visitor a faster, smoother experience from the moment they land on the store.
